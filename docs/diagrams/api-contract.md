# API Contract — Review-I

The authoritative API contract is auto-generated by FastAPI/OpenAPI at `/docs` when the backend is running.

| Method | Path | Login | Purpose |
|---|---|---|---|
| GET | `/api/health` | No | Service health |
| POST | `/api/v1/auth/register` | No | Register employee |
| POST | `/api/v1/auth/login` | No | Login and receive JWT |
| POST | `/api/v1/exit-requests` | Yes | Submit exit request |
| GET | `/api/v1/exit-requests/mine` | Yes | View own requests |
| GET | `/api/v1/exit-requests` | HR/Admin | View all requests |
| GET | `/api/v1/exit-requests/dashboard` | HR/Admin | View request counts |
| PATCH | `/api/v1/exit-requests/{request_id}/decision` | HR/Admin | Approve or reject |

## Common Response Format

```json
{
  "success": true,
  "data": {},
  "message": "Operation completed"
}
```
