# Review-I Demo Script

1. Explain the problem: employee exits are difficult to track when handled through email and spreadsheets.
2. Show the architecture diagram.
3. Show the ER diagram and explain the five tables.
4. Open the application and create an employee account.
5. Submit an exit request with a future last working date.
6. Show the employee request as `pending`.
7. Log out and log in as HR using the demo account.
8. Show the HR dashboard and pending request.
9. Approve the request.
10. Explain that approval creates clearance tasks for IT assets, HR documents and Finance clearance.
11. Show Swagger at `/docs` and explain that FastAPI generated the API documentation automatically.
12. Show the GitHub commit history and explain the Conventional Commit messages.
